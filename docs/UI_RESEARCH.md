# BSPHP 在线后台 UI 调研

新版整体视觉规范已经单独整理在
[UI_STYLE_GUIDE.md](UI_STYLE_GUIDE.md)，采用“现代蓝白管理台”方向。

> 调研日期：2026-07-18  
> 调研范围：登录页、后台框架、个性化参数页、软件管理页。  
> 用途：提取信息架构和高价值交互，不直接复制旧页面源码。

## 1. 参考截图

### 登录页

![BSPHP 登录页](assets/bsphp-login-reference.png)

结构：

- 居中大卡片，左右分栏。
- 左侧品牌、系统说明。
- 右侧管理员账号、密码、安全码、语言和登录按钮。
- 浅蓝灰背景、蓝色主按钮、较大的输入区域。

新版处理：

- 保留左右分栏和清晰品牌区。
- 手机端折叠成单列。
- 首版确定不使用验证码。
- 首版语言先使用简体中文。
- “安全码（二级密码）”是否进入新版登录，单独确认；它与图形验证码不是同一概念。

### 后台框架

![BSPHP 后台框架](assets/bsphp-admin-reference.png)

结构：

- 深蓝色顶栏。
- 左侧多级折叠菜单。
- 顶部页签。
- 主内容由 iframe 加载。
- 底部有实时帮助向导。

新版处理：

- 保留左侧分组导航、当前页状态和操作入口。
- 桌面端保留侧栏；手机端改为抽屉与底部导航。
- 使用 Laravel 正常路由和 Blade Layout，不继续使用 iframe 页签。
- 帮助内容改成页面右侧说明或帮助抽屉。

### 软件管理

![BSPHP 软件管理](assets/bsphp-app-management-reference.png)

软件以大卡片展示，每个应用卡片含：

- 应用名称、代号、授权模式。
- 用户总数、今日/昨日/本月新增。
- 在线连接数、在线设备数。
- 卡总数、已激活、未激活、今日/昨日/本月激活。
- 原版展示库卡总数、剩余库卡、库卡账户数；新版不采用这套概念。
- 用户分组和卡类型数量。
- 原版包含配置软件、用户列表、库卡列表、充值卡列表、卡类型、用户分组、
  库卡增减、现卡/导入制卡等入口。

这个页面的信息设计值得保留，但新版会减少同屏密度：

- 应用列表先显示核心指标。
- 详细统计放入应用详情。
- 常用动作放主按钮。
- 低频动作放“更多”菜单。
- 手机端每个应用显示为可折叠卡片。

范围修正：

- 移除“库卡列表”“库卡增减”“库卡归零”和“库卡账户”入口。
- 保留卡密管理、卡种、批次、生成/导入、手动发卡和代理提卡。
- 可用库存是普通卡密状态的统计结果，不作为单独业务模块展示。

## 4. 个性化参数设计

在线后台允许修改以下 Legacy 参数名：

- `m`
- `appid`
- `parameter`
- `mutualkey`
- `api`
- `date`
- `md5`
- `BSphpSeSsL`
- `appsafecode`

这是旧版值得保留的高级能力。新版建议分成两层：

1. **系统默认参数名**
2. **应用覆盖参数名**

后台修改前展示客户端示例，保存后生成新的 Objective-C/PHP/cURL 调用片段，并保留修改日志。

## 5. UI 实现原则

- 参考旧版的信息结构，不照搬旧 CSS 和 iframe 技术。
- 登录页继续使用左右分栏视觉，手机端单列。
- 应用页以卡片作为主对象。
- 列表页支持筛选、批量操作和导出。
- 危险操作与常规操作分组。
- 代理看见的按钮由权限决定。
- 每个配置页同时显示说明和默认值。
- 高级协议项默认折叠，减少误改。
