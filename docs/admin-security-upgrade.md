# 管理员账号与单端登录升级

## 行为

- 管理员列表的操作弹窗支持修改普通管理员用户名、登录密码和二级密码。二级密码留空保持原设置，填写后自动启用，两个密码须不同。
- 当前登录账号（含超级管理员）使用列表上方“个人安全设置”、当前账号行“修改账号”，或右上角“修改密码”入口。修改须验证当前登录密码；已启用二级密码时还须验证当前二级密码。
- 个人安全设置支持修改用户名、登录密码、启用/更换/关闭二级密码。保存后重新登录。
- 后台 admin guard 每个账号仅保留一个有效登录 token：新登录替换旧 token，旧端下一次请求即退出。同一浏览器的标签页共享同一会话。
- token 使用 32 字节随机值，数据库只保存 SHA-256 摘要，原值仅保存在服务器会话中。每个后台请求重新读取数据库并检查账号状态和 token。
- 修改用户名、登录密码、二级密码、状态或主角色时撤销旧 token。旧浏览器退出不会撤销新登录。凭据校验期间发生改密或冻结时，登录 token 的条件更新失败。
- 管理员登录失败日志只记录账号与原因，不再保存尝试密码；历史管理员失败日志的密码展示入口已屏蔽。既有数据库记录和备份未清理。
- 二级密码字段从验证失败的 old input 中排除；已登录后台响应设置 no-store。

本次单端策略针对管理员后台，未变更代理端及软件客户端各自的会话策略。

## 部署

使用项目要求的 PHP 8.3+，在发布新代码时先完成数据库迁移，再开放后台请求：

```sh
php artisan migrate --force
php artisan optimize:clear
```
