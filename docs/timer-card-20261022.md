# 计时卡：客户端冻结 / 恢复计时

## 后台制卡

软件 → 现卡制作，勾选「制作为计时卡」。只有时长类型可以制作计时卡，普通卡不能冻结。

- 冻结次数上限：-1 为不限。
- 单次最长冻结（天）：0 为不限；超过后自动恢复计时（按到点时间结算，不需要客户端调用）。

卡列表的充值状态旁会显示「计时卡」或「冻结计时中」，卡操作日志记录「冻结计时 / 恢复计时」。
公开激活码查询页对计时卡额外显示剩余时长。

## 客户端接口（卡串模式，AppEn.php）

参数与 `login.ic` 相同：卡号、卡密码（如有）、机器码 `key`、`appsafecode`。机器码必须与卡绑定的设备一致。

| api | 作用 |
| --- | --- |
| `pause.ic` | 冻结计时 |
| `resume.ic` | 恢复计时（未冻结时调用也返回成功） |
| `timer.ic` | 只查询，不改变状态 |
| `login.ic` | 冻结中的卡登录时自动恢复计时，旧客户端无需改动 |

成功返回（竖线分隔）：

```
01|状态|剩余秒数|到期时间|已冻结次数|次数上限|自动恢复时间|服务器时间
01|paused|864000|2026-11-01T22:53:40+08:00|1|5|2026-11-21T22:53:40+08:00|2026-10-22T22:53:40+08:00
```

- 状态：`paused` 冻结中，`active` 计时中。
- 到期时间：冻结中表示「此刻恢复」时的到期时间。
- 自动恢复时间：只在冻结中且设置了单次最长冻结时有值。

明文返回的错误（其他卡密错误仍统一伪装为「卡密不存在」）：

| 错误码 | 含义 |
| --- | --- |
| `TIMER_NOT_SUPPORTED` | 不是计时卡 |
| `TIMER_NOT_ACTIVATED` | 尚未激活，请先登录 |
| `TIMER_ALREADY_PAUSED` | 已经在冻结中 |
| `TIMER_PAUSE_LIMIT` | 冻结次数已用完 |

冻结不会断开在线会话，也不影响心跳。

## 代理联动

冻结中的计时卡在同步快照里为 `status: "paused"`，并额外带 `remaining_seconds`；DFMProxy 按非 active 处理，删除该用户并断开连接。
恢复后下一次同步（最长约 30 秒）恢复为 `active` 和新的到期时间。其他用户的字段不变。
