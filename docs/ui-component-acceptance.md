## 已完成

- 代理登录、中控台、卡管理、余额制卡、财务管理使用 Vue 3 + Element Plus。
- 导航使用 ElMenu 和 ElTabs；容器、栅格、间距使用 ElContainer / ElRow / ElCol / ElSpace。
- 表格、固定操作列、搜索、分页、标记按钮、数字输入、确认框、弹窗、消息、统计、标签采用组件库。
- 代理端未新增自绘控件样式表；保留旧页面仅作为无 JavaScript 情况下的服务器渲染展示。
- 软件列表、软件配置/新增、用户列表、用户详情和批量维护复用相同组件库；弹窗按内容设置高度。
- 修复旧工作区重复处理组件表单的问题，保留工作区提交与重定向上下文。
- 修复表单中 name="action" 覆盖 form.action 的兼容性问题。
- 原路由、CSRF、请求方法、隐藏字段、服务端价格、权限过滤和校验保持不变。
- 制卡金额以整数分计算；余额不足提示；免费卡正常处理；标记请求在途时防重复点击。
- 手机端卡号与处置优先展示；编号和标记合并到卡号区域，其余字段可横向滚动。
- 去除中控台重复且容易误解的“全国”指标，保留当前代理的真实统计范围。
