# MyBsPHP 重新安装与安装锁

## 1. 三种状态

| 状态 | 安装器行为 |
|---|---|
| 新数据库 | 正常创建表、管理员和安装锁 |
| 数据库已有表 | 默认保留应用和卡密，也可选择清空全部数据 |
| 已存在 `storage/installed.lock` | `/install` 简单提示“已安装，需要重装请删除 installed.lock” |

安装状态只以 `storage/installed.lock` 为准。手动删除该文件后，重新访问 `/install`
即可进入五步安装向导，不需要修改 `.env`。

## 2. 已有数据库的两种模式

### 保留应用和卡密（默认）

- 保留应用、Legacy 配置、卡种、批次、卡密和手动发卡记录。
- 清空后台管理员、角色权限、软件用户、系统设置、系统日志、Session、缓存和队列数据。
- 原业务记录中的操作管理员字段自动变为空，不影响卡密继续使用。
- 安装最后一步创建新的超级管理员。

### 清空全部数据

- 删除整个数据库并重新创建。
- 应用、卡密和发卡记录也会清除。
- 最后一步必须输入完整数据库名并再次确认。

## 3. BSPHP 习惯的手动重装

1. 访问 `/install`。
2. 页面显示简单提示：

```text
已安装
如果需要重新安装，请删除 installed.lock 文件。
```

3. 在项目目录手动删除实际文件 `storage/installed.lock`。
4. 刷新 `/install`，重新进入环境检测和五步安装向导。
5. 继续使用原数据库时，保持默认的“保留应用和卡密”。
6. 需要全新空库时选择“清空全部数据”并完成数据库名确认。

锁文件删除后，原数据库不会立刻变化。数据处理只会在安装最后一步执行。

## 4. 一次性维护链接方式

先在服务器项目目录运行：

```bash
cd laravel
/opt/homebrew/opt/php@8.3/bin/php artisan mybsphp:reinstall-link
```

Linux 服务器上 PHP 8.3 已作为默认命令时，也可以运行：

```bash
php artisan mybsphp:reinstall-link --ttl=30
```

命令生成一个默认 30 分钟有效的一次性 URL，有效期可在 1～120 分钟间设置。使用该
URL 进入安装向导后：

1. 页面显示“重装维护模式已授权”。
2. 选择“保留应用和卡密”或“清空全部数据”。
3. 选择清空全部数据时，最后输入数据库名并再次确认。
4. 安装成功后令牌立即删除，新的安装锁覆盖旧锁。

令牌文件名只保存 SHA-256 摘要，文件权限为 `0600`；URL 首次成功授权 Session 后立即消费，
普通 `/install` 请求仍返回安装锁定页。

该方式适合不方便直接操作服务器文件的部署环境；手动删除锁文件和一次性维护链接都保留。

## 5. 数据保护

- 重新安装前先完成数据库备份。
- 清空全部数据需要手动输入数据库名，避免误选。
- 管理员创建与 `super_admin` 角色绑定在同一事务中，失败会一起回滚。
- 数据库迁移、管理员、环境文件和安装锁全部成功后才显示安装完成。
- `storage/installed.lock` 和 `storage/framework/reinstall-tokens/` 已加入 `.gitignore`。
