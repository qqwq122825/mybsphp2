# MyBsPHP 覆盖安装与安装锁

## 1. 三种状态

| 状态 | 安装器行为 |
|---|---|
| 新数据库 | 正常创建表、管理员和安装锁 |
| 数据库已有表、站点尚未安装完成 | 停止继续，提示选择新数据库或勾选覆盖安装 |
| 已存在 `storage/installed.lock` | `/install` 显示“系统已安装成功”和需要删除的锁文件 |

安装状态只以 `storage/installed.lock` 为准。手动删除该文件后，重新访问 `/install`
即可进入五步安装向导，不需要修改 `.env`。

## 2. 未完成安装时覆盖

1. 返回安装向导“连接数据库”步骤。
2. 确认数据库地址、用户名和密码。
3. 勾选“覆盖现有数据库”。
4. 完成站点和管理员设置。
5. 在最后一步输入完整数据库名。
6. 勾选最终覆盖确认后执行安装。

覆盖动作会删除所选数据库的全部表并重新创建。安装器在数据库步骤只检测和记录选择，
真正删除发生在最后确认之后。

## 3. BSPHP 习惯的手动重装

1. 访问 `/install`。
2. 页面确认系统已经安装，并显示需要删除的文件：

```text
storage/installed.lock
```

3. 在项目目录手动删除该文件。
4. 刷新 `/install`，重新进入环境检测和五步安装向导。
5. 继续使用原数据库时，勾选“覆盖现有数据库”。
6. 最后输入完整数据库名并再次确认清除。

锁文件删除后，原数据库不会立刻变化。数据库清除只会在安装最后一步完成二次确认后执行。

## 4. 一次性维护链接方式

先在服务器项目目录运行：

```bash
cd laravel
/opt/homebrew/opt/php@8.3/bin/php artisan mybsphp:reinstall-link
```

Linux 服务器上 PHP 8.3 已作为默认命令时，也可以运行：

```bash
php artisan mybsphp:reinstall-link --ttl=30
```

命令生成一个默认 30 分钟有效的一次性 URL，有效期可在 1～120 分钟间设置。使用该
URL 进入安装向导后：

1. 页面显示“重装维护模式已授权”。
2. 选择数据库并勾选覆盖。
3. 最后输入数据库名并再次确认。
4. 安装成功后令牌立即删除，新的安装锁覆盖旧锁。

令牌文件名只保存 SHA-256 摘要，文件权限为 `0600`；URL 首次成功授权 Session 后立即消费，
普通 `/install` 请求仍返回安装锁定页。

该方式适合不方便直接操作服务器文件的部署环境；手动删除锁文件和一次性维护链接都保留。

## 5. 数据保护

- 覆盖前先完成数据库备份。
- 覆盖数据库名需要手动输入，避免误选。
- 管理员创建与 `super_admin` 角色绑定在同一事务中，失败会一起回滚。
- 数据库迁移、管理员、环境文件和安装锁全部成功后才显示安装完成。
- `storage/installed.lock` 和 `storage/framework/reinstall-tokens/` 已加入 `.gitignore`。
