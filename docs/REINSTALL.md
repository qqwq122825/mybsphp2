# MyBsPHP 覆盖安装与安装锁

## 1. 三种状态

| 状态 | 安装器行为 |
|---|---|
| 新数据库 | 正常创建表、管理员和安装锁 |
| 数据库已有表、站点尚未安装完成 | 停止继续，提示选择新数据库或勾选覆盖安装 |
| 已存在 `installed.lock` 或 `.env` 中 `APP_INSTALLED=true` | 后台登录保持可用，普通访问 `/install` 跳回后台 |

仅删除 `storage/installed.lock` 不是完整重装方式，因为 `.env` 和数据库仍保留安装状态。

## 2. 未完成安装时覆盖

1. 返回安装向导“连接数据库”步骤。
2. 确认数据库地址、用户名和密码。
3. 勾选“覆盖现有数据库”。
4. 完成站点和管理员设置。
5. 在最后一步输入完整数据库名。
6. 勾选最终覆盖确认后执行安装。

覆盖动作会删除所选数据库的全部表并重新创建。安装器在数据库步骤只检测和记录选择，
真正删除发生在最后确认之后。

## 3. 已安装站点重新安装

先在服务器项目目录运行：

```bash
php bin/enable-reinstall.php
```

命令生成一个 30 分钟有效的一次性 URL。使用该 URL 进入安装向导后：

1. 页面显示“重装维护模式已授权”。
2. 选择数据库并勾选覆盖。
3. 最后输入数据库名并再次确认。
4. 安装成功后令牌立即删除，新的安装锁覆盖旧锁。

令牌文件只保存 SHA-256 摘要，权限为 `0600`；URL 首次成功授权 Session 后立即消费，
普通 `/install` 请求仍会跳回后台登录。

## 4. 数据保护

- 覆盖前先完成数据库备份。
- 覆盖数据库名需要手动输入，避免误选。
- 管理员创建与 `super_admin` 角色绑定在同一事务中，失败会一起回滚。
- 数据库迁移、管理员、环境文件和安装锁全部成功后才显示安装完成。
- `storage/installed.lock` 和 `storage/reinstall-token.json` 已加入 `.gitignore`。
