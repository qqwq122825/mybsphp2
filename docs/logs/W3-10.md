# W3-10 · 侧栏动效与入口信息精简

## 基本信息

- 日期：2026-07-19
- 状态：DONE
- 负责人：主 Agent
- 依赖：W3-9

## 目标

- 删除侧栏底部的后台路径展示。
- 让侧栏、一级菜单和快捷入口的展开/收起更连贯。

## 实现

- 侧栏底部不再输出入口文字和 `/admin` 类路径。
- 桌面侧栏在 226px 和 68px 之间使用 240ms 缓动过渡。
- 工作区网格与侧栏宽度同步过渡，收起按钮图标跟随旋转。
- 一级菜单的箭头旋转，二级内容通过 `details::details-content` 完成展开/收起过渡。
- 右上角快捷入口增加下移、淡入和轻微缩放动效。
- 对 `prefers-reduced-motion` 同步降低动画和过渡时长。
- 静态资源版本更新为 `w414-motion`。

## 验收

- 功能测试确认后台页面不再输出侧栏入口文字。
- 浏览器确认侧栏 226px/68px 切换、菜单折叠和快捷入口正常。
- 桌面宽度 1437px 时无横向溢出。
- Composer 完整检查通过：PHPUnit 50 tests / 424 assertions，PHPStan 0 错误，Pint 通过。
