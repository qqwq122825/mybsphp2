# W3-3：Laravel Gate/Policy 权限层

**状态：DONE** · **日期：2026-07-19**

## 目标

让 RBAC 关系真正控制后台路由、页面数据、菜单与操作入口，形成默认拒绝的后台权限基线。

## 实现

- 新增 `AdminPermission` 权限码目录，首批登记 26 个后台能力。
- 在 `AppServiceProvider` 中为全部权限码注册 Laravel Gate。
- 新增 `AdministratorPolicy`，覆盖管理员查看、新建、修改、删除动作。
- 管理首页路由增加 `can:dashboard.view` 中间件。
- 后台认证中间件在当前请求切换到独立 `admin` Guard，并预加载角色权限。
- 管理员角色与权限改为一次预加载后在内存中判断，避免侧栏逐项产生重复查询。
- 五个一级菜单、全部二级入口、快捷操作和手机底部入口按权限显示。
- 无 `audit.view` 时不查询、不输出最近审计记录，避免只隐藏菜单但仍泄露页面数据。
- 超级管理员通过 `super_admin` 角色获得登记权限全集。
- 普通管理员对未明确授予的权限默认拒绝。
- 管理员 Policy 阻止管理员删除自身。

## 测试

- 普通管理员只能通过已绑定角色获得能力。
- 未授予能力默认返回 false。
- 冻结管理员即使拥有角色权限也无法通过 Gate。
- 超级管理员通过全部 26 个已登记权限。
- Administrator Policy 的查看、修改、删除和新建映射正确。
- 管理首页无 `dashboard.view` 时返回 403。
- 有限权限管理员只看到允许的一级/二级菜单，审计内容不会输出。
- PHPUnit：36 tests / 230 assertions。
- PHPStan：0 错误。
- Pint：通过。
- Composer 清单严格校验通过。
