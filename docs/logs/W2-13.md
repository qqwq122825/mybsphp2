# W2-13：BSPHP 风格安装锁提示与删锁重装

**状态：DONE** · **日期：2026-07-19**

## 目标

保持原 BSPHP 的使用习惯：已安装时访问 `/install` 显示安装成功和锁文件路径；管理员手动
删除该文件后，刷新页面即可重新安装。

## 实现

- `InstallationManager::isInstalled()` 只检查安装锁文件。
- 新增简洁的已安装提示页，只展示“已安装”和删除 `installed.lock` 文件的说明。
- 锁文件不存在时，即使 `.env` 仍为 `APP_INSTALLED=true`，安装向导也会正常打开。
- 数据库已有表时进入 W2-14 的“保留应用和卡密 / 清空全部数据”选择。
- 最终安装不再要求重复输入数据库名。
- 一次性重装维护链接继续可用，适配不方便直接删除文件的服务器环境。

## 自动化测试

- 有锁文件时 `/install` 显示已安装页和 `installed.lock` 提示。
- 删除锁文件后 `/install` 显示步骤 1 环境检测。
- 删除锁后动态后台入口重定向安装向导。
- `APP_INSTALLED=true` 不会覆盖锁文件状态。
- 一次性重装链接回归通过。
- 全量结果：44 tests / 333 assertions，PHPStan 0 错误，Pint 通过。

## 浏览器验收

- 实际打开 `http://127.0.0.1:8091/install`，显示简洁的 `installed.lock` 提示。
- 临时移动真实锁文件后刷新，浏览器进入五步安装向导步骤 1。
- 将锁文件原样恢复并设置权限 `0600`，页面恢复已安装状态。
- 当前数据库、管理员和后台入口保持不变。
- 390px 页面宽度与滚动宽度均为 390px。
