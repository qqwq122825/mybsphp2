# SCOPE-1：移除原版库卡模块

**状态：DONE**

**日期：2026-07-18**

## 决定

新版不实现原版独立的“库卡列表”模块，同时移除相关的库卡增减、库卡归零和库卡账户
界面。

## 保留能力

- 卡密管理
- 卡种与批次
- 卡密生成和导入
- 后台手动发卡
- 代理按等级价提卡
- 卡密归属及发卡记录

## 数据口径

“可用库存”直接统计普通卡密表中符合可售状态且尚未分配的记录。代理已提取的卡密通过
卡密归属和提卡记录查询，不再维护额外的库卡余额或库卡账户。

## UI 约束

桌面侧栏、手机导航、应用详情和快捷入口均不出现“库卡”名称，统一使用“卡密”。
