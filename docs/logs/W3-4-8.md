# W3-4～W3-8：角色种子、权限约束与管理员维护

**状态：DONE** · **日期：2026-07-19**

## 目标

把 W3-2/W3-3 的 RBAC 数据层和 Gate 执行层补成可重复安装、可维护、可审计的后台权限闭环。

## 实现

- 建立 `SystemAccessSynchronizer` 与 `SystemAccessSeeder`，安装和手动 Seeder 共用同一套同步逻辑。
- 固化超级管理员、管理员和代理三个系统角色。
- 权限目录扩充到应用状态、卡密敏感字段、批次、发卡、导出、解绑审批等业务能力。
- 超级管理员拥有全部登记能力；管理员排除删卡与删管理员；代理只获得明确可分配能力。
- 代理默认排除删卡、任意作废卡密、解绑设备、管理软件账户、角色权限和后台管理员。
- 新增管理员列表、创建、角色/状态维护以及可选二级密码。
- 管理员创建和维护写入统一审计日志。
- 首次安装在迁移后自动同步角色权限，避免新环境出现角色表为空。

## 测试与验收

- Seeder 重复执行保持幂等。
- 三个角色及代理权限模板断言通过。
- 管理员创建、密码最少 6 位、二级密码与角色更新断言通过。
- 浏览器打开 `/nnnnnnnnnnxxx/administrators`，角色基线、创建表单和账号列表均正常。
- 当前账号标识正确；页面说明明确展示代理高影响权限限制。
- 全量工程检查：42 tests / 307 assertions，PHPStan 0 错误，Pint 通过。

## 遗留
