# W2-0：旧安装器与在线登录页交互调研

**状态：DONE**

**日期：2026-07-19**

## 目标

审阅旧版 BSPHP、8090 已确认原型和在线登录页面，冻结 Laravel 正式版安装器与管理员
登录页面规格，为 W2-1～W2-11 提供统一实现基线。

## 审阅内容

1. `示例/index.php` 与 `示例/install/` 的安装检测、环境检测、MySQL 和安装标记。
2. `示例/nnnnnnnnnnxxx/` 的外部可变后台目录设计。
3. 8090 的五步安装向导、覆盖安装、重装令牌和登录页。
4. 在线 BSPHP 登录参考与已登录后台的实际 DOM、菜单和 iframe 结构。
5. W0-8 二级密码决策、`REINSTALL.md` 和整体 UI 风格指南。

## 冻结结果

- 正式安装器使用环境、数据库、站点、管理员、完成五步流程。
- 默认后台入口为 `/admin`，安装时可修改为 3～48 位安全路径。
- 初始账号默认 `admin`，可编辑。
- 主密码最少 6 位，二级密码为默认关闭的可选开关。
- 登录页固定简体中文，字段只有账号、密码和条件显示的二级密码。
- 非空数据库默认停止；覆盖操作在最终安装前要求数据库名与确认框。
- 已安装站点通过服务器本地短时一次性令牌进入重装维护 Session。
- 已安装状态访问 `/install` 返回安装锁定页，不展示动态后台入口。
- 登录页面使用蓝白左右分栏，390px 隐藏左侧视觉区。
- 登录提交继续位于动态后台路由组，旧默认路径在修改后返回 404。
