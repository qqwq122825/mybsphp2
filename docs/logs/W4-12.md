# W4-12 · BSPHP 模式后缀与默认登录 API

## 基本信息

- 日期：2026-07-19
- 状态：DONE
- 负责人：主 Agent
- 依赖：W4-11、W8-0

## 实现

- 核对 BSPHP 新版文档的 `.ic`、`.lg`、`.in` 后缀规则。
- 卡密验证限时模式自动使用 `login.ic`。
- 账户注册与充值模式自动使用 `login.lg`。
- 卡密模式参数默认为 `icid/icpwd`，账户模式默认为 `user/pwd`。
- 通信配置页把登录 API 改为只读默认值，说明后缀由软件模式决定。
- 服务端在创建、保存和首次创建 Legacy 配置时统一计算默认 API。
- 迁移脚本会按模式校正已有软件数据。
- 新增 `docs/BSPHP_API_COMPATIBILITY.md` 作为后续 `.ic/.lg/.in` 实现清单。

## 验收

- 卡密模式保存时即使提交 `login.lg`，服务端仍保持 `login.ic`。
- 账户模式创建后自动写入并显示 `login.lg`。
- 开发数据库迁移已应用。
- Composer 完整检查通过：PHPUnit 50 tests / 435 assertions，PHPStan 0 错误，Pint 通过。
- Chrome 验收确认 `login.ic` 为只读默认值，页面无横向溢出。
