# W4-15 · 临时工作标签与单行卡类型表单

## 基本信息

- 日期：2026-07-19
- 状态：DONE
- 负责人：主 Agent
- 依赖：W4-14

## 实现

- 卡串类型和现卡制作入口使用前端临时工作标签加载。
- 打开工作页时浏览器地址保持软件管理地址。
- 临时标签只保存在当前页面内存，刷新后回到软件管理并清空临时标签。
- 临时标签支持切换与关闭，表单提交后仍留在当前工作标签。
- POST 表单使用同后台路径返回地址校验，保持验证错误回到原工作页。
- 卡类型添加表单调整为一行一项：字段名、输入控件、说明文字三列排列。
- 手机端自动折叠为单列字段布局。
