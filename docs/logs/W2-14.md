# W2-14：已有数据库默认保留业务数据

**状态：DONE** · **日期：2026-07-19**

## 目标

删除安装锁后重新安装时，减少已有数据库的重复确认。默认保留应用和卡密，只重置系统账户；
同时保留明确的全量清空选项。

## 模式

### 保留应用和卡密（默认）

- 保留：应用、Legacy 配置、卡种、卡密批次、卡密、手动发卡及其明细。
- 重置：后台管理员、角色权限、软件用户、系统设置、审计日志、Session、缓存和队列。
- 创建新的超级管理员并重新同步系统角色权限。

### 清空全部数据

- 删除数据库后重新创建并执行全部迁移。
- 在数据库步骤选择该模式后，最终直接确认安装。

## 测试

- 新增 `SystemAccountResetterTest`，生成真实应用、卡种、批次、卡密和发卡记录。
- 执行系统账户重置后，管理员/权限/日志/设置/用户均为空。
- 应用、卡种、批次、2 张卡密、发卡记录和发卡明细完整保留。
- 旧管理员外键自动置空。
- 安装数据库页面默认选中 `preserve_business`。
- 全量结果：47 tests / 362 assertions，PHPStan 0 错误，Pint 通过。

## 浏览器验收

- 数据库步骤显示两种模式。
- “保留应用和卡密”默认选中并带默认标记。
- 两个单选项均可切换，验收结束后恢复默认保留模式。
- 选择清空模式并通过真实数据库连接测试后，最终页面不再显示数据库名输入和重复确认框。
- 最终页面只保留管理员设置、安装确认和“确认清空并安装”按钮，未提交最终安装。
- 当前真实数据库未执行提交或清除。
