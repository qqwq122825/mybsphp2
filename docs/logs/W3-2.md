# W3-2：管理员、角色与权限数据层

**状态：DONE** · **日期：2026-07-19**

## 目标

建立后台 RBAC 数据关系，同时把原版 BSPHP 的一级/二级菜单习惯整理为首版精简导航。

## 实现

- 新增 `roles` 与 `permissions`。
- 新增 `administrator_roles` 与 `role_permissions`，均使用复合主键。
- 外键删除规则只清理关联数据，不影响审计记录。
- 权限记录包含模块、风险等级和代理可分配标记。
- 创建 `super_admin`、`admin` 两个安装必需系统角色。
- 迁移现有管理员的旧 `role` 值，并在新安装事务内绑定超级管理员角色。
- 新增 Role、Permission 关系模型和管理员角色/权限查询。
- 后台侧栏改为五个一级分类和可折叠二级菜单。

## UI 范围

- 参考原版的信息层级和菜单展开方式。
- 首版隐藏用户反馈、邮件、短信、验证码、在线支付、推广佣金、文章栏目和插件。
- 完整清单：[`W3_NAVIGATION_SCOPE.md`](../W3_NAVIGATION_SCOPE.md)。

## 测试

- RBAC 表与启动角色存在。
- 管理员多角色、角色多权限双向关系可查询。
- 超级管理员具有全权限语义。
- 复合主键拒绝重复角色分配。
- 删除权限后关联记录按外键清理。
- 当前开发库现有 `admin` 已关联 `super_admin`。
