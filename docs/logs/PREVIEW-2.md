# PREVIEW-2 · 修复首次安装重复管理员

## 基本信息

- 日期：2026-07-18
- 状态：DONE
- 范围：安装 UI 原型

## 现象

```text
SQLSTATE[23000]: Integrity constraint violation:
1062 Duplicate entry 'admin' for key 'users.username'
```

## 根因

旧原型的初始迁移缺少 `roles` 和 `user_roles`。首次安装先写入管理员，随后授予
`super_admin` 角色时失败；管理员写入没有事务回滚，重试时触发用户名唯一索引。

## 修复

- 新增管理员 RBAC 迁移，创建角色、权限和关联表并初始化系统角色。
- 管理员写入与超级管理员角色绑定放入同一数据库事务。
- 任一步失败时回滚管理员记录。
- 对已存在用户名返回明确提示。
- 重置本次失败安装产生的空白测试数据库后重新进入向导。

## 验证

- PHP 语法检查通过。
- 001/002/003 在临时 MySQL 数据库中顺序执行通过。
- `super_admin` 角色和 RBAC 表存在。
- 管理员与角色绑定事务测试通过。
- 密码与授权原有测试通过。
