# W4-11 · 工作区导航与软件配置标签

## 基本信息

- 日期：2026-07-19
- 状态：DONE
- 负责人：主 Agent
- 依赖：W3-1、W4-10、W8-0

## 目标

- 参考新版 BSPHP 增加后台工作区页面标签导航。
- 把软件配置重新分为“基本配置、通信安全、限开控制”。
- 保持手机端可操作且页面本身无横向溢出。

## 实现

- 顶栏下新增工作区导航：侧栏收起/展开、后台首页、当前业务页面标签和刷新入口。
- 软件页面依次显示“软件管理、添加新软件、软件代号-软件配置”。
- 软件配置新增三个 ARIA Tab：
  - 基本配置：软件资料、状态、版本、公告和验证数据 `a[2]`。
  - 通信安全：通信 Key、服务器地址、加密算法、证书、Objective-C 宏和 AppEn 参数。
  - 限开控制：设备绑定数与最大并发会话。
- 标签通过 URL Hash 记录当前位置，支持左右方向键切换。
- 服务端校验出错时自动打开相应配置分类。
- 手机端两层标签在自身容器内横向滑动，不扩张页面宽度。
- 参考新版 BSPHP 将软件配置主体合并为单张白色圆角卡片，标题、分类标签、内容和保存栏
  处于同一容器。
- 分类内部移除重复的大卡片边框与标题占位，通信配置行高统一为 53px。
- 服务器证书与 Objective-C 宏收进按需展开区域，默认页面保持紧凑。
- CSS/JS 地址加入版本参数，刷新页面即可载入当前样式。
