# W2-12：账号级二级密码与新版登录 UI

**状态：DONE** · **日期：2026-07-19**

## 目标

补齐后台登录页的二级密码可见性、账号级校验和管理员自助维护入口，并按新版 BSPHP
浅色双栏页面重新验收桌面与手机布局。

## 实现

- 登录页固定渲染“安全码（二级密码）”输入框，未启用账号可留空。
- 登录时先匹配账号，再按该账号的 `secondary_password_required` 状态决定是否校验。
- 新增当前账号安全表单，支持启用、更新和关闭二级密码。
- 修改安全设置前校验当前主密码；主密码和二级密码内容必须不同。
- 二级密码继续使用 Laravel hashed cast 保存，审计只记录开关状态。
- 登录页采用浅蓝背景、左侧 BSPH 品牌区、右侧表单区；手机端切换为单栏。
- 保持“语言”下拉框不进入首版页面。

## 自动化测试

- 无二级密码账号可留空登录。
- 开启二级密码的账号在全局安装开关关闭时仍执行账号级校验。
- 缺少或填写错误二级密码均被拦截，正确二级密码可以登录。
- 当前管理员可以在主密码验证后启用和关闭自身二级密码。
- 全量结果：43 tests / 321 assertions，PHPStan 0 错误，Pint 通过。
