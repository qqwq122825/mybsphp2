# W4-1～W4-9：应用与协议配置主流程

**状态：CORE DONE** · **日期：2026-07-19**

## 目标

让管理员可以创建、查看、编辑和停用应用，并为卡密登录协议配置业务值、签名与设备策略。

## 数据与实现

- 新增 `applications` 与 `application_legacy_configs` 表。
- 应用使用独立公开 ID，客户端密钥只在创建成功后展示一次，数据库加密保存。
- 支持 `card_login` 与 `account_recharge` 模式选择。
- 支持启用/停用、版本号、业务值、诱饵值、设备绑定、并发上限和 Legacy 参数名。
- 应用列表展示状态、模式、卡种数和卡密数。
- 新建、编辑、状态切换均走 Gate 权限并写入审计。
- 每日签名使用应用密钥和 UTC 日期生成 10 位签名。

## 测试与验收

- 应用创建、敏感密钥加密、编辑和停用 Feature 测试通过。
- 状态变更独立检查 `applications.status.update`。
- 浏览器实际创建 `card_login` 演示应用，并在列表看到 1 个应用、关联卡种和卡密统计。
- 桌面与窄屏均无横向溢出。
- 全量工程检查：42 tests / 307 assertions，PHPStan 0 错误，Pint 通过。

## 遗留

- `account_recharge` 当前完成模式与配置入口，账户、点数和充值交易在 W7 实现。
- 并发上限已保存，在线会话执行在 W6-6 实现。
