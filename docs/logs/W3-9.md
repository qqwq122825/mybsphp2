# W3-9 · 深蓝工具栏、图标侧栏与快捷入口

## 基本信息

- 日期：2026-07-19
- 状态：DONE
- 负责人：主 Agent
- 依赖：W3-1、W4-11

## 目标

- 参考新版 BSPHP 顶部工具栏与侧栏收起交互。
- 侧栏收起后保留一级菜单图标，而不是完全移出页面。
- 增加右上角快捷入口下拉菜单。

## 实现

- 后台顶部改为深蓝渐变工具栏，左侧保留品牌、侧栏切换和刷新按钮。
- 桌面侧栏支持 226px 完整模式与 68px 图标模式。
- 图标模式显示五个一级菜单图标，隐藏菜单文字、二级菜单和后台路径。
- 五个图标保留原生悬停名称提示，便于识别当前一级分类。
- 工作区随侧栏在 226px/68px 两种起点间切换，页面宽度保持稳定。
- 右上角新增“快捷入口指引”，包含软件管理、卡密查询、手动发卡、修改密码和退出。
- 点击菜单外部或按 Escape 可收起快捷菜单。
- 手机端继续使用 260px 抽屉；桌面工具按钮在窄屏隐藏。
- CSS 与 JavaScript 静态资源版本更新为 `w412-rail`。
