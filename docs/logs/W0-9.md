# W0-9 · 确认代理层级和余额提卡规则

## 基本信息

- 日期：2026-07-18
- 状态：DONE
- 负责人：AI Agent
- 依赖：W0 阶段需求确认、代理业务调研

## 目标

- 确认首版代理层级、代理价格、余额账本、提卡事务、权限和数据范围。

## 本任务范围

包含：

- 一级代理和代理等级。
- 管理员手动充值/扣减。
- 按应用/卡种等级价自助提卡。
- 整数分金额模型。
- 默认权限、数据范围、事务、幂等和审计。
- 验收条件与延后项。

不包含：

- Laravel 业务代码。
- 数据库迁移。
- 代理后台 UI。
- 在线支付、返佣或多级代理。
- 自动化测试代码。

## 契约/设计

### API

- 本任务为业务决策，不新增 API。
- 已定义后续提卡请求必须包含应用、卡种、数量和幂等请求号。
- 已定义代理身份必须从服务端会话取得，不能信任请求中的代理 ID。

### 数据库

- 本任务不创建 Migration。
- 已确定金额使用整数分，余额更新、钱包流水、提卡单、库存和归属必须以事务保持一致。
- 已确定价格维度为“代理等级 + 应用 + 卡种”。

## 实现

- 确认首版仅支持一级代理，代理等级仅用于定价。
- 确认管理员手动调整余额，代理按有效等级价自助提卡。
- 定义最小权限模板，默认禁止删卡、解绑、账户管理、改价和余额管理。
- 定义只读自身数据的数据范围。
- 定义余额与库存并发锁、幂等、不可变流水及审计规则。

- 余额和库存存在并发一致性风险，已明确使用数据库事务、行锁、唯一约束和幂等键。
- 一级代理模型减少首版复杂度；未来扩展多级代理时需独立迁移和重新审查数据范围。
