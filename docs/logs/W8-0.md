# W8-0 · iOS 通信凭据与混合加密网关

## 基本信息

- 日期：2026-07-19
- 状态：DONE
- 负责人：主 Agent
- 依赖：W4-10、W6-5

## 目标

- 创建软件时自动生成可直接复制到 iOS 的通信配置。
- 设计纯 Objective-C/Objective-C++ 可接入的请求与响应加密协议。
- 把加密封包接入 `/AppEn.php` 和现有卡密激活 Service。

## 本任务范围

包含：

- 软件代号限制为 1～20 位纯数字。
- 自动生成网关 Token、通信认证 Key、RSA-2048 密钥对和旧版兼容密钥。
- 软件配置页显示服务器地址、公钥、Objective-C 宏和复制按钮。
- RSA-OAEP + AES-256-CBC + HMAC-SHA256 v2 封包。
- 时间窗、nonce 一次性消费、请求/响应上下文绑定。
- `api=login.ic` 解密分派和加密返回。
- iOS Security.framework + CommonCrypto 参考实现。

不包含：

- 账户注册/登录/充值 action。
- 旧版表单 + 3DES 网关适配器。
- 风险诱饵策略 UI。

## 契约/设计

### API

- Method：`POST`
- URL：`/AppEn.php?appid={纯数字软件代号}&md5={网关Token}`
- Auth：通信认证 Key HMAC + RSA 服务器公钥封装的临时会话密钥
- Request：JSON v2 加密封包
- Response：JSON v2 加密封包，明文为固定 `login.ic` 竖线数组
- Error：`INVALID_GATEWAY`、`INVALID_PACKET`、`PACKET_REPLAYED`、
  `UNKNOWN_API` 及卡密业务错误码

### 数据库

- Migration：`2026_07_19_000009_add_application_communication_credentials.php`
- 兼容修正：`2026_07_19_000010_normalize_application_hybrid_cipher.php`
- 字段：网关 Token、加密后的通信 Key、加密模式、服务器公钥、加密后的服务器私钥、
  加密后的旧版兼容密钥。

## 实现

- `ApplicationCredentialService` 统一生成和补齐每个软件的独立凭据。
- `HybridPacketCipher` 完成封包、解包、字段规范化、HMAC 和 Base64URL。
- `LegacyGatewayController` 完成应用定位、解包、nonce 防重放和 `login.ic` 调用。
- iOS 参考类负责请求封包、响应验签解密和 RSA PKCS#1 公钥导入。

## 风险与回滚

- 软件私钥只在服务端加密保存；客户端仅持有服务器公钥和通信认证 Key。
- 旧客户端过渡使用独立 18 位兼容密钥，不与新版会话密钥混用。
- 两个 Migration 都提供 `down()`。

## 决策

- 新软件默认使用现代混合加密。
- 为兼容 iOS Objective-C++ 和 PHP OpenSSL，正文采用 AES-256-CBC + HMAC，而不是依赖
  iOS 版本差异较大的 GCM 封装。
- `a[2]` 继续完全由软件“验证数据”提供。
