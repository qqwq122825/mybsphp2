# W4-17 · BSPHP 充值卡类型字段

## 基本信息

- 日期：2026-07-19
- 状态：DONE
- 负责人：主 Agent
- 依赖：W4-16、W5-1～3

## 实现

- 参考 BSPHP 添加充值卡类型页面，移除可见的类型代号输入，服务端以 ULID 派生唯一内部识别值。
- 表单按一行一项提供充值卡软件、别名、开头字符、备注、排序、期限及单位、价格、代理价格和余额充值。
- 卡号、密码分别配置长度与字符组合；密码长度允许为 0，制卡服务支持生成无附加密码的卡串。
- 增加账号同时在线数、机器同时使用量，约定 `0` 继承软件配置、`-1` 关闭对应限制。
- 保留前缀大小写，卡号总长度严格等于配置值；列表隐藏内部识别值并按排序值展示。
