# MyBsPHP2 整体 UI 风格指南

> 状态：**已确认并完成首批实施**  
> 方向：参考 BSPHP 原版的蓝白后台气质，重新实现为现代、清晰、响应式管理系统。  
> 原则：借鉴信息架构和视觉语言，不延续 iframe、旧式页签和固定桌面宽度。

## 1. 最终风格定位

风格名称：

```text
Modern BSPHP Blue / 现代蓝白管理台
```

关键词：

- 专业。
- 清晰。
- 轻量。
- 蓝白配色。
- 信息密度适中。
- 接近原版用户习惯。
- 手机与电脑使用同一套设计语言。

当前黑绿登录页、超大衬线标题和霓虹色品牌块退出主视觉。系统默认使用浅色模式，深色模式
作为后续可选主题。

## 2. 颜色系统

| 变量 | 色值 | 用途 |
|---|---|---|
| `--primary-600` | `#3867E8` | 主按钮、活动菜单、链接 |
| `--primary-700` | `#2E55CA` | Hover、按下状态 |
| `--primary-100` | `#E9F0FF` | 选中背景、标签 |
| `--navy-950` | `#111A38` | 顶栏渐变起点 |
| `--navy-800` | `#244A96` | 顶栏渐变终点 |
| `--page-bg` | `#F3F6FC` | 全局页面背景 |
| `--surface` | `#FFFFFF` | 面板、表单、卡片 |
| `--surface-soft` | `#F8FAFE` | 次级区域 |
| `--text-900` | `#172033` | 主文字 |
| `--text-600` | `#66738A` | 说明文字 |
| `--border` | `#E2E7F0` | 边框与分隔线 |
| `--success` | `#22A06B` | 成功、正常 |
| `--warning` | `#E49A24` | 警告、库存不足 |
| `--danger` | `#DD4B5C` | 风险、删除、错误 |

页面不使用大面积纯黑；蓝色只用于品牌和交互重点，避免整个内容区过度鲜艳。

## 3. 字体与尺寸

- 中文：系统字体、`PingFang SC`、`Microsoft YaHei`。
- 英文和数字：`Inter`、系统无衬线字体。
- 页面标题：24–30px，字重 700。
- 面板标题：16–18px，字重 650。
- 正文：14px。
- 辅助文字：12–13px。
- 表格行高：48–52px。
- 表单控件：44–48px。
- 手机触控区域最小 44px。

管理系统不使用大面积艺术衬线字体，确保中文后台信息清楚、稳定。

## 4. 圆角、边框与阴影

- 页面大面板圆角：12px。
- 卡片圆角：10px。
- 输入框和按钮圆角：8px。
- 标签圆角：6px 或胶囊形。
- 常规边框：1px `#E2E7F0`。
- 卡片阴影：`0 8px 24px rgba(37, 64, 122, 0.07)`。
- 不使用夸张发光、玻璃拟态和大范围模糊阴影。

## 5. 登录页

桌面端参考原版结构：

```text
浅蓝渐变页面背景
┌────────────────────────────────────────────┐
│ 左侧品牌说明 50%  │ 右侧白色登录表单 50% │
│ BSPH              │ 管理员登录            │
│ 后台管理系统       │ 账号                  │
│ 简短说明           │ 密码                  │
│                    │ 条件显示的二级密码    │
│                    │ 蓝色登录按钮          │
└────────────────────────────────────────────┘
```

规则：

- 页面主卡片最大宽度约 1360px，最大高度不强制固定。
- 左侧使用极浅蓝渐变和抽象曲线背景，保持留白。
- 右侧表单最大宽度 520px。
- 二级密码按系统开关显示。
- 首版固定简体中文，页面移除语言选择器。
- 错误提示放在表单标题下方，不改变整体布局。
- 390px 手机端隐藏左侧大面板，只保留品牌标题和登录卡片。

## 6. 后台整体框架

### 桌面端

```text
┌──────────────────── 顶栏 64px ────────────────────┐
│ BSPH  折叠菜单  刷新                  管理员  退出 │
├──────── 侧栏 240px ───────┬───────────────────────┤
│ 控制台                    │ 面包屑 / 当前页签      │
│ 应用管理                  ├───────────────────────┤
│ 卡密管理                  │ 页面标题 + 操作按钮    │
│ 账户管理                  │ 指标卡 / 表格 / 表单   │
│ 代理管理                  │                       │
│ 风险与审计                │                       │
│ 系统设置                  │                       │
└───────────────────────────┴───────────────────────┘
```

规则：

- 顶栏使用原版相近的深蓝渐变。
- 左侧栏使用白色背景，菜单组用极浅灰蓝容器区分。
- 当前菜单使用浅蓝背景 + 蓝色文字 + 3px 左侧强调线。
- 内容区使用浅灰蓝背景，核心内容放白色面板。
- 保留面包屑，不继续使用原版 iframe 页签。
- 列表页右上角放主要操作，例如“创建应用”“生成卡密”。
- 首页使用 4 个指标卡、应用概览、库存提示、最近操作和快捷入口。
- 侧栏和应用详情不设置原版“库卡列表”入口；统一使用“卡密管理”。

### 手机端

- 顶栏高度 56px，显示品牌、页面标题和菜单按钮。
- 侧栏变为左侧抽屉。
- 首页指标卡改为 2 列，窄屏可变为 1 列。
- 表格自动转卡片列表，关键字段优先显示。
- 底部导航只放“首页、应用、卡密、我的”四个高频入口。
- 批量操作进入底部操作栏，避免横向挤压。

## 7. 首页信息架构

第一屏：

1. 页面标题、欢迎语和系统运行状态。
2. 今日验证、可用卡密、在线设备、风险事件四个指标。
3. “创建应用”“生成卡密”“手动发卡”三个快捷按钮。

第二屏：

1. 应用概览卡。
2. 卡密库存与低库存提醒。
3. 最近登录/风险事件。
4. 最近管理员操作。

空数据状态使用清晰插图图标 + 说明 + 主要动作，不出现“基础框架已经就绪”等开发期文案。

## 8. 组件规范

统一组件：

- `PageHeader`
- `Breadcrumb`
- `StatCard`
- `Panel`
- `DataTable`
- `MobileDataCard`
- `StatusBadge`
- `PrimaryButton / SecondaryButton / DangerButton`
- `TextInput / Select / Switch / Checkbox`
- `Alert / EmptyState / ConfirmDialog`
- `Drawer / Pagination / FilterBar`

同一状态保持固定颜色：

| 状态 | 颜色 |
|---|---|
| 正常、可用、成功 | 绿色 |
| 草稿、等待、普通信息 | 灰蓝 |
| 注意、库存不足 | 橙色 |
| 冻结、风险、失败 | 红色 |
| 当前选择、主要动作 | 品牌蓝 |

## 9. 动效

- Hover/Focus：120–160ms。
- 抽屉、弹窗：180–220ms。
- 桌面侧栏宽度切换：240ms，工作区同步伸缩。
- 一级菜单折叠：160–220ms；箭头旋转与内容高度使用同一节奏。
- 快捷下拉：180ms 淡入、小幅下移，不使用明显弹跳。
- 页面切换不使用大幅移动和缩放。
- 支持 `prefers-reduced-motion`。
- 表单提交只锁定提交按钮，不让整个页面闪动。

## 10. UI 验收

每个核心页面检查：

- 390 × 844 手机。
- 768 × 1024 平板。
- 1280 × 800 笔记本。
- 1440 × 900 桌面。

必须满足：

- 无横向溢出。
- 主操作在首屏可见。
- 输入框、按钮和菜单可键盘操作。
- Focus 状态清晰。
- 文本与背景对比度符合 WCAG AA。
- 空数据、加载、错误和权限不足均有明确状态。
- 登录、创建应用、生成卡密和手动发卡在手机端可单手完成。

## 11. 实施顺序

1. 重做登录页。
2. 重做顶栏、侧栏、内容容器。
3. 重做后台首页。
4. 建立按钮、输入、面板、表格和状态标签。
5. 完成 390/768/1280/1440 响应式检查。
6. 后续业务页面只组合已有组件，避免重新定义视觉。

## 12. 首批实施结果

- 管理员登录页已切换为蓝白左右分栏。
- 后台已切换为白色顶栏、白色分组侧栏和浅灰蓝内容区。
- 首页已实现指标卡、应用空状态、快捷操作和最近动态。
- 手机端已实现抽屉导航、两列指标和底部快捷导航。
- 后台顶栏下已增加工作区页面标签：侧栏控制、首页、当前业务标签和刷新入口。
- 桌面顶栏使用深蓝渐变；侧栏在 226px 完整模式与 68px 一级图标模式间切换。
- 右上角快捷入口使用白色下拉菜单，点击外部或按 Escape 收起；手机继续使用抽屉侧栏。
- 软件配置采用二级标签“基本配置 / 通信安全 / 限开控制”；手机端标签容器独立横向滚动。
- 详情配置页面优先使用单张主卡片，卡片内通过紧凑行和折叠高级内容控制纵向长度；
  通信凭据等只读行的桌面目标高度约 52px。
- 侧栏参考原版一级/二级层级，使用可折叠一级分类和单层二级页面；范围见
  [`W3_NAVIGATION_SCOPE.md`](W3_NAVIGATION_SCOPE.md)。
