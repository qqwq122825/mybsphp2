# 自瞄功能使用说明

## 📋 功能概述

已成功将自瞄功能集成到 UAM 游戏辅助项目中，包含完整的UI设置界面和实时自瞄执行逻辑。

---

## 🎯 设置项说明

### 1. **自瞄开关**
- 类型：开关（UISwitch）
- 功能：开启/关闭自瞄功能
- 默认值：关闭

### 2. **自瞄距离**
- 类型：滑块（UISlider）
- 范围：0 - 300 米
- 功能：只对距离小于此值的敌人进行自瞄
- 默认值：100 米
- 实时显示：当前数值

### 3. **自瞄范围**
- 类型：滑块（UISlider）
- 范围：0 - 200 像素
- 功能：FOV 圆的半径，只对此范围内的敌人自瞄
- 默认值：50 像素
- 实时显示：当前数值

### 4. **自瞄模式**
- 类型：分段控制（UISegmentedControl）
- 选项：
  - **开火**：预留给开火检测（当前总是激活）
  - **开镜**：预留给开镜检测（当前总是激活）
  - **镜火全开**：预留给镜火检测（当前总是激活）
- 默认值：开火模式
- 注意：⚠️ 当前版本所有模式都总是激活，需要在 GameOffset.h 中添加相关偏移后才能实现状态检测

### 5. **锁定模式**
- 类型：分段控制（UISegmentedControl）
- 选项：
  - **准星优先**：优先瞄准离屏幕中心最近的敌人
  - **距离优先**：优先瞄准距离最近的敌人
- 默认值：准星优先

### 6. **自瞄速度**
- 类型：滑块（UISlider）
- 范围：0.00 - 1.00
- 功能：控制自瞄的移动速度（越大越快）
- 默认值：0.50
- 实时显示：精确到小数点后两位

### 7. **瞄准部位**
- 类型：分段控制（UISegmentedControl）
- 选项：
  - **脖**：瞄准方框上部 1/4 处
  - **胸**：瞄准方框中心偏上（40% 处）
  - **腿**：瞄准方框下部（75% 处）
  - **居中**：瞄准方框正中心（50% 处）
- 默认值：胸部
- 注意：由于 UAM 游戏未获取骨骼数据，使用方框位置计算

### 8. **自瞄触摸点** ⭐ 新增
- 类型：可点击项（带右箭头）
- 功能：设置自瞄触摸模拟的起始点位置
- 默认值：(0, 0) - 使用屏幕右下角默认点
- 使用方法：
  1. 点击进入触摸点选择界面
  2. 拖动红色圆点到想要的位置
  3. 可选：点击"打开图片"加载游戏截图辅助定位
  4. 点击"完成"保存位置
- 显示：实时显示当前设置的坐标 (X, Y)
- 建议：选择游戏中不影响操作的区域（如右下角、屏幕边缘等）

## 🎮 工作原理

### 目标选择流程：
```
1. 遍历所有玩家（排除人机）
2. 获取瞄准部位的屏幕坐标
3. 检查是否在 FOV 范围内
4. 检查距离是否在自瞄距离内
5. 根据锁定模式评分（准星距离或实际距离）
6. 选择评分最优的目标
```

### 触摸模拟流程：
```
1. 检查自瞄开关和目标状态
2. 初始化触摸点：
   - 优先使用用户指定的触摸点
   - 否则使用默认点（屏幕右下角 90%, 80%）
3. 开始触摸：touchDownAtPoint（使用第9个手指，ID=10）
4. 持续移动：moveTouchToPoint（根据自瞄速度和目标偏移）
5. 达到目标：liftUpAtPoint（距离<2px时）
6. 坐标转换：横屏→竖屏（ConvertLandscapePointToPortrait）
7. 串行队列：防止触摸事件冲突
```

### 可视化显示：
- 🔴 红色圆圈：FOV 范围指示器
- 🔴 红色直线：从屏幕中心到目标的预瞄线
- 🔴 红色圆点（大）：目标锁定点
- 🟢 绿色圆点（小，调试模式）：指定触摸点位置
- 🟡 黄色文字（调试模式）：目标坐标、模式、速度等信息
- 🟢 绿色文字（调试模式）：触摸点坐标

## ⚠️ 注意事项

### 当前限制：
1. **自瞄模式暂不可用**：由于 GameOffset.h 中未定义 `bWantsToAim`（开镜）和 `bIsFiring`（开火）偏移，当前所有自瞄模式都是"总是激活"
2. **瞄准部位基于方框**：由于未获取骨骼数据，瞄准部位是方框的相对位置而非真实骨骼点
3. **人机不参与自瞄**：代码中已过滤 AI 玩家，只对真实玩家自瞄

### 优化建议：
1. 添加游戏状态偏移：在 GameOffset.h 中定义开镜/开火状态，可实现更精准的自瞄触发
2. 获取骨骼数据：如果能读取骨骼，可实现更精准的部位瞄准
3. 调整自瞄速度：根据实际游戏体验微调速度参数

## 📝 未来扩展

如需添加游戏状态检测，需要在 GameOffset.h 中添加：

```c
// 移动组件相关
#define CharacterMovementComponent 0xXXXX  // 需要逆向分析
#define bWantsToAim 0xXXXX                 // 是否正在开镜
#define bIsFiring 0xXXXX                   // 是否正在开火
```

然后在 SetControlRotation 函数中更新：
```objc
case 0: // 开火模式
    shouldActivateAimbot = Read<bool>(movementComp + bIsFiring, 1);
    break;
case 1: // 开镜模式
    shouldActivateAimbot = Read<bool>(movementComp + bWantsToAim, 1);
    break;
case 2: // 镜火全开
    shouldActivateAimbot = (bWantsToAim || bIsFiring);
    break;
```
